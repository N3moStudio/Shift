# Shift 2.4.4 — Finishing touches

**RELEASE 2.4.4** &nbsp; / &nbsp; Build 47 &nbsp; / &nbsp; N3mo Studio

A smoother path from source to iPhone. This update finishes the current Shift
release with corrected icon assets, a repaired build check and clearer downloads.

> **Download:** `Shift 2.4.4.ipa` from **Assets** below.
> Install through **SideStore**, keeping the app extension.

---

## What changed

| Refinement | The difference |
| :--- | :--- |
| **Dark & tinted icons** | Corrected filename capitalization so Xcode finds the default icon's appearance variants. |
| **GitHub builds** | Fixed the final icon check that rejected a successfully compiled app. Added 12 regression tests. |
| **Clearer downloads** | The workflow now supports direct IPA downloads named after the app version: **Shift 2.4.4.ipa**. |
| **Notifications** | Removed the temporary test-banner tool. Regular pairing and session notifications remain. |

## Included from the 2.4 refresh

- **Three styles, nine icons.** Glacier, Afterhours and Porcelain, with icon selection independent of the interface theme.
- **Native Map, Library and Settings tabs**, with Liquid Glass on supported iOS versions.
- **The first-launch crash fix**, alongside the existing route, library, joystick and optional helper features.

[Explore the full Locus → Shift changelog →](https://github.com/N3moStudio/Shift/blob/ff8d20436da5bdaade616f33bb3715cbbcaa0331/CHANGELOG.md)

## Install in three steps

1. Download **Shift 2.4.4.ipa** from the release assets.
2. Add it to **SideStore** and keep **LocusActivity** for Live Activities and widgets.
3. Open Shift and complete the Wi-Fi, LocalDevVPN and pairing checklist.

**Already using Shift?** Install over the existing app with the same signing
setup to retain its data. Export your library before changing installation methods.

[Setup guide](https://github.com/N3moStudio/Shift/blob/ff8d20436da5bdaade616f33bb3715cbbcaa0331/SETUP.md) · [Build from source](https://github.com/N3moStudio/Shift/blob/ff8d20436da5bdaade616f33bb3715cbbcaa0331/docs/BUILDING.md)

<details>
<summary><strong>Known behavior & limitations</strong></summary>

A successful location command does not prove what another app or person sees.
Find My **Devices** reports may be old and are separate from Find My People.

iOS controls background execution and ordinary notification icons, including
cached icons. Continuous background operation and immediate alerts are not guaranteed.
The notification-preview removal does not fix an iOS-cached banner icon.
