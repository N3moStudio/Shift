# Shift 2.4.4 — Make your next move

**Your map. Your pace.**

Shift by **N3mo Studio** brings location simulation, route planning and a personal
place library together in a native iPhone app. Built on Locus, this public
release brings together the current Shift experience and the latest build fixes.

## Three looks. Your choice.

- **Glacier, Afterhours and Porcelain:** three interface styles with light and dark palettes.
- **Nine app icons:** choose Default, Dark or Tinted from any family, independently of the interface style.
- **Native navigation:** Map, Library and Settings, with Liquid Glass on supported iOS versions and accessibility-aware presentation.

## Move your way

- Search for a place, preview and adjust a pin, then teleport.
- Plan with directions, tap route points, draw freehand or import GPX.
- Choose travel modes and speeds; add stops, waits and per-section settings.
- Pause, resume, jump along a route or use the map-relative joystick.
- Save places, named areas and trips; organize them with folders and search.
- Recover items through Recently Deleted, restore earlier trip edits, and export or import your library.

## Keep track

- Live Activities, Dynamic Island and widgets surface session information.
- Timestamped status distinguishes recent connection evidence from stale or unverified information.
- Optional Windows and self-hosted cloud helpers compare Find My **Devices** reports. Each user supplies their own service and credentials.
- Configurable **3–15 second connection checks** apply to Shift's connection evidence; Apple's location-report timing is separate.
- Quieter idle timers, paused-route work and buffered logs reduce unnecessary activity. No fixed battery-saving percentage is claimed.

## Fixes included

- Fixed the first-launch appearance crash introduced in the initial 2.4.0 build.
- Refined native tab navigation, route touch input, area-draft stability and joystick direction.
- Removed the temporary notification-preview feature in 2.4.4. Regular pairing and session notifications remain.
- Fixed the IPA validation error that stopped GitHub Actions after a successful Xcode build.
- Corrected the default icon's dark/tinted filename references for case-sensitive builds.
- Added 12 regression checks for icon declarations, resource filenames and IPA validation.
- Updated the build workflow for direct, automatically versioned IPA downloads, such as **Shift 2.4.4.ipa**.

This is a cumulative release overview. The [full changelog](https://github.com/N3moStudio/Shift/blob/v2.4.4/CHANGELOG.md)
records the changes from the original Locus base; intermediate versions are not required.

## Install

1. Download **Shift 2.4.4.ipa** from **Assets** below.
2. Sign and install it through **SideStore**. Keep the **LocusActivity** extension for Live Activities and widgets.
3. Open Shift and complete the Wi-Fi, LocalDevVPN and pairing checklist.
4. Updating an existing installation? Use the same signing setup and install over it to retain its data. Export your library before changing installation methods.

[Setup guide](https://github.com/N3moStudio/Shift/blob/v2.4.4/SETUP.md) · [Build it yourself](https://github.com/N3moStudio/Shift/blob/v2.4.4/docs/BUILDING.md)

**Version:** 2.4.4 · **Build:** 47 · **Minimum deployment target:** iOS 18.
The IPA still needs SideStore signing; its filename does not imply an Apple distribution signature.

## Validation and limits

- GitHub Actions completed a successful build after the icon-validation fix.
- Build logs recorded 279 Swift model tests and 69 helper tests passing; the 12 new packaging regression tests also passed locally.
- The maintainer confirmed that the IPA installs and works on their iPhone. This is a device smoke test, not a claim that every feature or supported configuration has been tested.

A successful location command does not prove what another app or person sees.
Find My Devices reports can be old and are separate from Find My People.
iOS controls background execution and ordinary notification icons, including
cached icons. Continuous background operation and immediate alerts are not guaranteed.
