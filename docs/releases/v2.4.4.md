# Shift 2.4.4 — Make your next move

**Native map controls. Three distinct looks. Your own pace.**

Shift by **N3mo Studio** is an independent, fully open-source evolution of
Locus for iPhone location simulation. This release includes the accumulated
route, library, status and appearance work, plus the latest launch and
navigation fixes.

## The experience

- **Glacier, Afterhours, Porcelain.** Three interface styles, light/dark palettes, native Liquid Glass on supported iOS versions, and nine independently selectable app icons.
- **Preview, then move.** Search and adjust a pin before teleporting. Use directions, draw freehand, tap out a route, or import GPX.
- **Routes that stay under your control.** Travel modes and speeds, stops and waits, pause/resume, route jumps, saved trips and a map-relative joystick.
- **A real library.** Named places and areas, folders, saved-name search, duplication, three-version trip history, Recently Deleted and export/import.
- **Visible evidence.** Live Activities, Dynamic Island, Home Screen shortcuts, recovery guidance and timestamped connection status.
- **Optional Find My helpers.** Use your own cloud service or Windows computer. No personal server, account or helper key is built in.

## Recent fixes and refinements

- **2.4.4:** removed the temporary test-banner feature. Existing notifications and native icon selection remain; no new polling or background work.
- **2.4.2:** refreshed native Map / Library / Settings tabs, kept navigation expanded while panning, corrected portable linked-SDK metadata, and included small system icon sizes for all choices.
- **2.4.1:** fixed the first-launch appearance-trait exception from the initial 2.4.0 build.
- Earlier updates stabilized area drafts, refined route touch input and map-relative joystick direction, simplified setup, and reduced unnecessary idle, paused-route and logging work.

The repository’s **CHANGELOG.md** records the full custom Locus → Shift history,
including superseded features and diagnostic builds. This list is cumulative;
you do not need to install intermediate versions.

## Download and install

1. Download **Shift-2.4.4.ipa** from Assets below.
2. Sign and install it through **SideStore**. Keep the **LocusActivity** extension; it supplies Live Activities and widgets.
3. Updating? Use the same signing setup and install over the current app. Export your library before changing installation methods or downgrading.
4. On first use, complete Shift’s Wi-Fi / LocalDevVPN / pairing checklist. The repository’s **SETUP.md** covers both on-device pairing where supported and RPPairing import.

**Version:** 2.4.4 · **Build:** 47 · **Minimum deployment target:** iOS 18.
The included IPA was compiled for arm64 iOS with SDK 27.1. Its signatures are
ad-hoc placeholders, not Apple distribution signatures; SideStore must sign it
for your device. Minimum OS support is not a claim of testing every iOS version.

The portable IPA includes all nine manual icon choices. Automatic use of custom
dark/tinted asset-catalog artwork requires an Xcode build; those source assets
are included. iOS still controls ordinary notification icons and may retain
an older cached icon.

## What the status can tell you

A successful location command is not proof of what another app or person sees.
Find My **Devices** reports are separate evidence and may be old; they are not
Find My People. Optional helper integrations are unofficial and can change.
iOS controls background execution and notifications, so uninterrupted monitoring
and immediate warnings are not guaranteed. No measured battery-saving percentage
is claimed.

## Validation

The included build passed **279 Foundation tests**, compiled the app and its
extension, and passed archive, identity, entitlement, icon and bundled-resource
checks. This public-source preparation keeps the runtime source unchanged.
The included public IPA redacts local compiler paths, preserves its executable
and data sections, and has verified ad-hoc signature/resource hashes. Its
checksum therefore differs from the earlier private build of the same version.
Native gestures, SideStore signing, helper account access and background behavior
still require testing on the actual device; these are not certified by model tests.
