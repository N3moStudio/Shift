# Shift · by N3mo Studio

Shift is the app. **N3mo Studio** is the creator label, pronounced “Nemo Studio.”
The current lead direction is **Glacier**: ice blue, silver, deep blue ink and
restrained glass. The older sea-glass ribbon remains only as retained legacy
artwork; it is not the current default icon.

| Style | Character | Light accent | Dark accent |
| --- | --- | --- | --- |
| Glacier | Ice blue & silver | `#255BA4` | `#B5D9FF` |
| Afterhours | Ink & violet | `#7142A9` | `#D1B4FF` |
| Porcelain | Chalk & graphite | `#323B3F` | `#DBE4E9` |

`AppearanceIcons/` contains the current three icon families, each in Default,
Dark and Tinted finishes, their SVG/PNG sources and a manifest. The app’s icon
catalogs and previews are under `Locus/Resources/`. Interface style and app icon
are independent preferences; do not silently link them.

The README cover/style images are layouts made from these existing assets,
not screenshots of a running iPhone. Their editable SVG sources live alongside
the PNGs in `docs/images/`. No font files are distributed.
